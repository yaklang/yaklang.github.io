# New homepage MP4 originals

This directory contains the original, pre-compression homepage videos. It is intentionally kept in Git so a production asset can be restored without re-encoding.

To restore the hero video from the repository root:

```bash
cp "static/img/newHome/_mp4_backup_20260807_105649/ascii-magic-47.mp4" \
  "static/img/newHome/ascii-magic-47.mp4"
```
