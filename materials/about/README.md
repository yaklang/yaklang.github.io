# 关于我们：公司主体与资质素材库

本目录用于整理 Yak Project 背后的公司主体、经营资质、管理体系和政府项目材料，供官网“关于我们”页面选用。首页“项目里程碑”仍以 Yakit、Yaklang、网络安全专用编程语言及网络安全开发环境 YAK 为核心，不把公司资质替代为产品或技术成果。

## 主体关系

万径安全是四维创智（北京）科技发展有限公司使用的品牌，Yak Project 及 Yakit、Yaklang 等项目由相关团队持续建设。

- 公司介绍：[万径安全官网](https://www.megavector.cn/aboutUs/)
- 团队介绍：[Yak Project 团队页](https://yaklang.com/team/)

正式上线时应以工商登记名称“四维创智（北京）科技发展有限公司”作为证书、名单和政府项目中的主体名称；“万径安全”用于品牌介绍。

## 暂不发布的材料

- 无证书编号、认证范围或有效期的 ISO、知识产权管理体系和高新技术企业表述；
- 无当前年度正式名单或证书的 CNNVD 支撑单位级别；
- 把检测机构的 CNAS 认可写成公司或产品获得 CNAS 认证；
- 只有公众号截图、没有主管机构名单或证书原件的公司荣誉；
- 将“入选项目”“参与标准”“通过检测”统一包装成“政府认证”。

## 内部素材补充清单

后续可向万径安全团队集中收集：

1. 国家级专精特新“小巨人”证书及最终名单页；
2. 高新技术企业证书编号、发证日期和有效期；
3. ISO 27001 等管理体系证书的认证机构、范围和有效期；
4. CMMI Institute 官方查询页或证书；
5. CNNVD、CNVD 当前有效身份及证书；
6. 政府项目入选通知、任务书中允许公开的封面和项目名称页；
7. 标准发布页、标准封面及列有起草单位的前言页。

对外发布时，每项材料至少保留“正式名称、主体、年份、有效期或项目状态、原始证据”五个字段。
