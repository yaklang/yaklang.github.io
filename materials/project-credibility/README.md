# Yak Project 项目可信度素材包

本目录为官网“项目里程碑”和独立“完整发展历程”页面提供文案、证据与图片索引。内容选择以可核验为前提，不把普通活动照片、团队自述或无法公开复核的结论作为首页可信度证明。

## 首页使用范围

首页采用 [`README.md`](../../README.md#项目里程碑) 中的 9 个节点。每个节点只保留：

1. 年份；
2. 事件；
3. 事件对项目可信度的实际影响；
4. 一个能够直接支持该事实的证据链接。

首页主时间线不放人物介绍、详细获奖名单、会议过程和多张图片。这些内容进入 [`full-history.md`](./full-history.md)。

## 图注模板

- **2021：** 2021 年，Yak 与 Yakit 在 XCon 对外发布。
- **2023：** 2023 年 5 月，CDSL-YAK 开源发布会在北京国家会议中心举行。
- **2023：** YAKIT 网络安全单兵测试系统 V2.0 列入第十七批北京市新技术新产品（服务）名单第 694 项。
- **2024：** Yakit V2.0 按 GB 42250—2022、GB/T 37931—2019 完成网络安全专用产品测试。
- **2024：** 2024 中国信息通信大会现场。会上正式发布 2023 年度信息通信领域十大科技进展，YakLang 相关成果入选。
- **2025：** IRify 对外发布，Yak SSA、SyntaxFlow 和 AI 能力形成独立代码审计产品。
- **2025：** 中国通信学会 2025 年科学技术奖公告将 Yak 与开发环境相关成果列为一等奖。
- **2025：** “国产化网络安全开发环境 YAK”获得第十届“创客中国”全国总决赛企业组三等奖。
- **2026：** Memfit AI 对外发布，Yaklang 与 Yakit 的安全能力进入 Agent 工作流。

## 素材使用原则

- 正式机构页面优先于媒体稿，媒体稿优先于搜索摘要和论坛转载。
- 不用相似会议、其他年份颁奖现场或无明确图注的合影替代目标事件。
- 人物不作为认可结论的主体。涉及专家评审时使用会议现场、议程或正式结论，不突出个人肖像。
- 动态 GitHub 数据在实现时通过 GitHub API 获取，并显示统计口径与更新时间，不把 README 中手填数据当作长期证据。
- 外部图片在正式上线前确认版权和原图授权；无法确认时只保留证据链接，或改用团队自有原图。
