# Yak Project 项目可信度素材包

本目录为官网“项目里程碑”和独立“完整发展历程”页面提供文案、证据与图片索引。内容选择以可核验为前提，不把普通活动照片、团队自述或无法公开复核的结论作为首页可信度证明。

## 首页使用范围

首页采用 [`README.md`](../../README.md#项目可信度证明) 中的 6 个节点。每个节点只保留：

1. 年份；
2. 事件；
3. 事件对项目可信度的实际影响；
4. 一个能够直接支持该事实的证据链接。

首页主时间线不放人物介绍、详细获奖名单、会议过程和多张图片。这些内容进入 [`full-history.md`](./full-history.md)。

## 图注模板

- **2021：** 2021 年，Yak 与 Yakit 在 XCon 对外发布。图片用于证明公开发布场合，不用于证明后续技术评价。
- **2023：** 2023 年 5 月，CDSL-YAK 开源发布会在北京国家会议中心举行。图片用于证明开源发布事件和场合。
- **2024：** 2024 中国信息通信大会现场。会上正式发布 2023 年度信息通信领域十大科技进展，YakLang 相关成果入选。
- **2025：** 中国通信学会 2025 年科学技术奖公告将 Yak 与开发环境相关成果列为一等奖。使用证书或现场照片时，应与公告中的成果名称一致。
- **IRify / Memfit AI：** 使用产品界面说明产品已经发布和具备实际交付形态，不延伸推导用户规模或第三方评价。

## 素材使用原则

- 正式机构页面优先于媒体稿，媒体稿优先于搜索摘要和论坛转载。
- 不用相似会议、其他年份颁奖现场或无明确图注的合影替代目标事件。
- 人物不作为认可结论的主体。涉及专家评审时使用会议现场、议程或正式结论，不突出个人肖像。
- 动态 GitHub 数据在实现时通过 GitHub API 获取，并显示统计口径与更新时间，不把 README 中手填数据当作长期证据。
- 外部图片在正式上线前确认版权和原图授权；无法确认时只保留证据链接，或改用团队自有原图。
