# Yak Project 录屏剧本

本目录集中存放官网产品演示、宣传视频和素材拍摄剧本。产品定位与核心文案保留在仓库根目录的 `README.md`，具体录制流程在此维护。

| 产品 | 剧本 | 内容 |
| --- | --- | --- |
| IRify | [IRify 录屏剧本](./irify.md) | SSA 与 SyntaxFlow、AI 代码审计、规则调试与扫描稳定性 |

## 通用要求

- 录屏统一使用本地脱敏工程、虚构数据或公开靶场。
- 不得出现客户代码、真实凭据、未授权资产、Cookie、Token 或公网测试目标。
- 尚未在当前版本上线的能力必须在字幕中明确标注，不得以完成态展示。
- 长耗时过程可以剪辑压缩，但应保留输入、执行和结果之间的因果关系。
- 每支视频独立验收，也可以按产品合并为长版。
